# Intent-Preserving Protocol (IPP)

> An open specification and operational constitution for preventing stateless dissipation and unauthorized execution in agentic AI.

## ⚡ The Problem

As AI agents gain autonomous capabilities, two failure modes dominate:
1. **Stateless Context Dissipation:** Crucial human intent, negative constraints, and evolutionary rationale vanish when a chat session terminates.
2. **Hyperactive Over-reach:** Agents mistake exploratory discussions for execution authorization, mutating codebases or triggering tool executions without explicit permission.

## 📜 Core Axioms

The Intent-Preserving Protocol establishes **four non-negotiable axioms**:

1. **`Shaped ≠ Granted` (Decoupled Execution):** Cognitive convergence on an idea never grants execution authorization. The human author retains the sovereign ignition key.
2. **Raw Intent Immutability:** Author statements are append-only. AI derives trade-offs and counter-examples without overwriting the original motivation.
3. **Explicit Epistemic Layering:** Facts, AI hypotheses, and human decisions are strictly partitioned.
4. **Living Artifact as Truth:** Plaintext version-controlled files (Markdown) replace opaque vector memory as the sole source of truth.
