# Contributing to the Intent-Preserving Protocol (IPP)

Thank you for your interest in contributing to the Intent-Preserving Protocol!

IPP is an open specification designed to create safer, more auditable, and intent-aligned human-agent collaboration patterns.

---

## How Can You Contribute?

### 1. Propose an RFC (Request for Comments)
If you have an improvement to the core specification, a new axiom candidate, or extensions for multi-agent workflows:
- Open a GitHub Issue using the **RFC Proposal** template.
- Clearly state the problem, the proposed specification change, and how it preserves authorial agency.

### 2. Submit a Reference Implementation
If you have built an open-source Skill, MCP server, or Agent Framework module adhering to IPP:
- Submit a PR adding your project to the `Reference Implementations` table in `README.md`.
- Include the `[![IPP Compliant](https://img.shields.io/badge/IPP-Compliant-success.svg)](...)` badge in your repository.

### 3. Improve Documentation & Translations
- Corrections, clarifications, and community translations of `SPEC.md` are warmly welcomed!

---

## Code of Conduct

Please maintain a constructive, respectful, and welcoming environment for all contributors.
